# Xilinx Zynq-7000 Z-7010

The Zynq-7000 family combines a Processing System with ARM Cortex-A9 cores and Programmable Logic. Board support therefore depends on the selected package, PS MIO configuration, board wiring, and the PL bitstream; the shared SoC name does not establish a board device tree or peripheral map.

HamGeek identifies the PlutoSDR Nano family as Zynq-7010. An independent Nano project identifies XC7Z010-CLG400. The exact package and hardware revision of an individual unit remain unverified.

Sources: [AMD Zynq-7000 overview](https://docs.amd.com/api/khub/documents/juMnxca71Tf2gfjmNyjM8A/content), [HamGeek Nano product page](https://www.hgeek.com/products/hamgeek-70mhz-6ghz-zynq7010-ad9363-sdr-software-defined-radio-development-board-for-pluto-sdr-matlab), and [independent measured Nano pin map](https://github.com/k-iseri/pluto-fw-isdbt/blob/be1dfec5df616de27737ecd31530ab84eea882aa/docs/pinout-nano.md).
