# Boot and recovery

The recorded chain uses native board firmware and a device tree, with microSD storage.
Serial console and all CPU cores have published physical results.
The source does not establish connector contacts, logic voltage, loader versions or a recovery procedure.
Preserve a known working card and verify the exact board firmware before replacing boot files.
There is no onboard power button or RTC in this record.

Source: `os-zero2w-reference` in [sources.json](../../sources.json).
