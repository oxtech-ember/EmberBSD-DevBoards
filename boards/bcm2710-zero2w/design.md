# Design transfer

Check exact memory, radio firmware, power and connector wiring for the intended revision.
Use the native-firmware and device-tree path documented for this profile. BCM2712 UEFI/ACPI evidence applies to those boards.
Resolve the large-transfer Wi-Fi limitation before choosing it for a sustained data path.
