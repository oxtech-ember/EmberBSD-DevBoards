# YS-M33 wall tablet: Allwinner A133

Use this profile to study the YS-M33 boot chain and its closed-enclosure USB installation path.
[Machine-readable profile](board.json) · [Boot and recovery](boot.md) · [Interfaces](interfaces.md) · [Design transfer](design.md)

The cable-installation evidence covers one unopened factory tablet. Peripheral evidence comes from a separate reference sample. It does not establish support for every YS-M33 revision, another A133 tablet, or a hotel fleet.
The board revision and exact panel assembly revision are unknown.

Start with the current [boot](boot.md) and [interface](interfaces.md) references. Source records in [sources.json](../../sources.json) retain the original evidence.
The detailed installation tools and their executable checks belong to [EmberBSD](https://github.com/oxtech-ember/EmberBSD), not this catalog.
Check the current owner documentation before any device operation.

The physical installation record is in [evidence/cable-install.json](evidence/cable-install.json).
It records a tested scenario, not a released installer.
